# ⚽ Universo Futbolístico

Simulador y constructor de universos de fútbol ficticios.

## Visión
Crear clubes, regiones, divisiones y competiciones; simular temporadas mediante azar; conservar la historia y permitir que emerjan dinastías, crisis, ascensos y sorpresas.

## Arquitectura prevista
- Frontend: React + TypeScript
- Backend: API TypeScript
- Base de datos: PostgreSQL
- Versionado: GitHub
- Backups y exportación de universos
